# App 1: Multi-AI Debate Arena (Original Lightweight HTML/JS Edition)

This folder contains the working copy of the original lightweight Single-Page Application (HTML5 + Tailwind CDN + FontAwesome + Vanilla JS).

- **Main File:** `index.html`
- **Backend API Requirements:** FastAPI backend running on port 8000 (`/api/debate/*`, `/api/models/*`, `/api/workspaces/*`).
- **Features:** 
  - Real-time SSE token streaming
  - Live 21-model arena grid
  - Workspace file deliverables viewer
  - Direct lightweight client-side state management
